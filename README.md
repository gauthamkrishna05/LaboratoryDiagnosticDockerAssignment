# Laboratory Diagnostic Management System

## Project Description

A web-based Laboratory Diagnostic Management System developed to manage laboratory-related information and provide an easy-to-use interface for users.

## Technologies Used

- HTML
- CSS
- JavaScript
- Docker
- GitHub

## Features

- Laboratory management interface
- Patient information management
- Diagnostic information management
- Interactive user interface
- Responsive design

## How to Run

Clone the repository:

git clone YOUR_GITHUB_REPOSITORY_URL

Open the project folder and run the application.

## Docker

The application is containerized using Docker.

Docker image and container are used to run the application in an isolated environment.
